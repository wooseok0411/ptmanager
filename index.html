설치 방법

휴대폰만 있으면 5분이면 끝나요.

  1. 라이선스 코드 받기구매하시면 PT-XXXX-XXXX 형태의 코드를 보내드려요.
  2. 위의 [앱 열기 · 설치하기] 누르기구글 계정으로 로그인해요. 처음이라면 forms.google.com을 한 번 열어 두면 좋아요.
  3. 구글 권한 허용"확인되지 않은 앱" 창이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용을 눌러요.
  4. 코드·이름·센터 입력 후 [설치하기]내 계정에 설문지와 회원 시트가 자동으로 만들어져요.
  5. 홈 화면에 추가브라우저 메뉴 → 홈 화면에 추가를 누르면 앱처럼 쓸 수 있어요.
