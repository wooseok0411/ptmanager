3. 앱이 접근하는 Google 데이터와 사용 목적

트레이너가 앱을 설치할 때 Google 권한 동의 화면에서 아래 접근을 허용합니다. 각 권한은 아래 목적으로만 사용합니다.

Google 설문지 (forms)트레이너 계정에 사전 상담 설문지를 만들고, 트레이너가 앱에서 문항을 수정하며, 제출된 응답을 읽어 회원 목록에 보여줍니다.
앱이 만든 Google 시트 파일 (drive.file)트레이너 계정에 회원 시트를 만들고, 처방 목표·회차별 프로그램·운동일지·정보 수정 내용을 저장하고 읽습니다. 앱이 직접 만든 파일에만 접근하며, 드라이브의 다른 파일이나 시트는 볼 수 없습니다.
이메일 주소 (userinfo.email)트레이너 본인 확인과 라이선스 코드·계정 연결에 사용합니다.

앱은 Google Drive의 다른 파일, Gmail, 연락처 등 위에 적지 않은 데이터에는 접근하지 않으며, 메일을 보내지 않습니다. 새 설문 제출 알림은 트레이너가 Google 설문지의 기본 기능(새 응답 이메일 알림)을 직접 켜서 Google로부터 받습니다.

Privacy Policy (English)

PT Manager GYMvis ("the app") is a Google Apps Script web app that helps personal trainers manage intake surveys, workout programs, and workout logs for their clients. Operator: Wooseok Sim, gymvis.manager@gmail.com. Effective October 22, 2026; last updated October 27, 2026.

  • Data accessed: With the user's consent, the app accesses only: (1) Google Forms — the intake form the app creates in the trainer's account, its questions, and its submitted responses (forms); (2) Google Drive files the app creates — only the client spreadsheet the app creates in the trainer's account, read and written through the Google Sheets API (drive.file); the app cannot see any other Drive files or spreadsheets; (3) the signed-in user's email address (userinfo.email, openid). The app does not access Gmail, contacts, or any other Drive files, and does not send email. The app does not create aggregated or anonymized data sets from Google user data.
  • Data use: Forms data is used to create and edit the trainer's intake form and to list new clients from its responses. Sheets data is used to store and display client goals, per-session programs, workout logs, and client status inside the app. The email address is used to identify the trainer and bind the license code to that account. Google user data is used only to provide these user-facing features.
  • Data sharing and transfer: We do not sell, rent, or transfer Google user data to any third party, including advertisers, data brokers, or AI/ML service providers. The operator runs no servers and never receives client data. Content leaves the trainer's account only when the trainer explicitly taps "Send to client", which hands the selected text to the phone's own share sheet (e.g., KakaoTalk, SMS). The operator stores only license codes and the email address of the account that used each code, to prevent license reuse.
  • Data protection: All data is processed inside Google's infrastructure (Google Forms, Google Sheets, Apps Script) and transmitted over HTTPS. The app runs with the signed-in user's own permissions (execute as the user accessing the app), so one trainer cannot access another trainer's data. The operator has no access to trainers' forms or sheets. License records are kept in Apps Script properties accessible only to the operator's account.
  • Data retention and deletion: Form responses and sheet data stay in the trainer's own Google account for as long as the trainer keeps them; the trainer can edit or delete them at any time in Google Forms/Sheets. Deleting the form and sheet in Google Drive removes all app data. App settings (trainer name, center name, retention period) are stored in Apps Script user properties tied to the trainer's own account and are no longer accessed once the trainer revokes access at myaccount.google.com/permissions. License records are kept while the service is used and deleted promptly on request to gymvis.manager@gmail.com.
  • Limited Use: PT Manager GYMvis's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The use of raw or derived user data received from Workspace APIs will adhere to the Google User Data Policy, including the Limited Use requirements.
  • AI/ML: The app does not use AI/ML models. Google user data, including Workspace API data, is never used to develop, improve, or train AI/ML models and is never transferred to third-party AI/ML services.
